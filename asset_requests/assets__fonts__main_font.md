# main_font.ttf

- **File:** `assets/fonts/main_font.ttf`
- **Size:** pixel font, designed for 8 px (and 16 px) size
- **Status:** missing (the game runs without it)

Main UI pixel font with a 1940s-50s signage/typewriter feel. Needs digits, $ and basic punctuation. See asset_requests/font_fixes.md for the letters that need redrawing (m, M, W, w, v, V, N, r, 1).

Style: pixel art, mid-1900s Texas oil boom, warm dusty palette, crisp pixels (no anti-aliasing), transparent background unless stated.
